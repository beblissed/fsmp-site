What changes, and when?

  • Preview and Save draft affect this editor immediately.
  • Exported menu labels, colors, icons and titles load after a backend restart.
  • The companion StaffCore adapter displays titles and icons. The shipped Java 26.3 pack animates the exact Mint wave (6 seconds) and Lilac shimmer (5 seconds) presets; other edited styles use a static gradient until a matching shader pack is built. TAB uses the readable static form.
  • Pack mappings are a preview and an export list. This editor does not create models, textures or a resource-pack archive.

Database logins, permission grants, balances, purchase receipts and crate odds are outside this editor.

Import, backup & export
Save your draft first. Exports contain presentation settings only.
Import
Use a file exported by this editor. Other YAML formats are not imported here. No database configuration is accepted.
Backup
Includes saved settings and your custom style library. Keep the previous exported file as your rollback copy.
Export for your backends
  1. Save and export the configuration.
  2. Keep a copy of the existing customization file.
  3. Put the same new file in each backend’s CosmeticsCore folder.
  4. Restart the backends and verify the result.
There is no live Apply button or server connection. Pack assets need their own build/export and reload workflow.
